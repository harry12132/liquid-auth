# 💧 liquid-auth

An ultra-aesthetic, zero-dependency authentication template for Next.js and Tailwind CSS. Built with frosted glassmorphism, animated mesh gradients, fluid micro-interactions, and Passkey support out of the box.

## ✨ Features

* **💧 Liquid Glassmorphism:** Deep backdrop blurs (`backdrop-blur-2xl`), specular highlights, and glowing ambient borders.
* **🎨 Dynamic Mesh Gradients:** Pure CSS background mesh with subtle ambient pulse animations—no heavy WebGL shaders or canvas overhead.
* **⚡ Smooth Tab Switcher:** Fluid sliding pill indicator for seamlessly toggling between Sign In and Sign Up modes.
* **🔑 OAuth & Passkey Ready:** Built-in UI slots for GitHub, Google, and WebAuthn / Face ID integration.
* **📱 Fully Responsive:** Clean layout across mobile devices, tablets, and desktop displays.
* **🤖 Vibecode-Friendly:** Clean, single-file modular architecture tailored for Cursor, Windsurf, and v0 prompts.
